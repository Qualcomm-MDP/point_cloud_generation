# Depth Map
In order to get the mapilllary point clouds run python3 reset.py to reset all the directories. Then run get_mapillary.py, and then linux.py. None of the scripts require any
command line arguments, but if you want to modify the area, modify the locations within the get_mapillary.py scripts. 

Visualize point clouds:
- python3 reset.py
- python3 get_mapillary.py
- python3 linux.py
